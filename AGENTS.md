# AGENTS.md — library

Репозиторий ресурсных библиотек Graphene. Общая модель продукта находится в
`../GRAPHENE.MD`, пользовательская документация — только в репозитории
`../docs`.

## Правила

- Перед изменением библиотеки прочитайте `../GRAPHENE.MD` и её модуль.
- Код, имена и комментарии — на английском; README и инструкции — на русском.
- Коммиты — Conventional Commits, без `Co-Authored-By`.
- Конструктор библиотечного ресурса возвращает общий handle `pipeline.Resource`
  или `pipeline.Attached`; жизненный цикл не дублируется локально.
- Нативные спецификации внешней системы сохраняются нативными типами.
- Secrets и большие данные передаются ссылками, не значениями.
- Внешние эффекты должны быть идемпотентны или иметь явно выбранную гарантию.
- Изменение публичной поверхности одновременно обновляет соответствующую
  страницу в `../docs`.
